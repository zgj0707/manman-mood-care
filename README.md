# 慢慢 · 情绪日记与自我关怀

一个面向学习、工作和社交压力场景的静态网页原型。包含即时情绪记录、触发因素标记、日记回看、近一周情绪线索、非诊断的近期自我观察、本地规则模拟的 AI 回顾，以及呼吸、轻活动和聆听练习。

## 隐私与实现边界

- 记录仅保存在当前浏览器的 `localStorage`，不会上传或同步到服务器。
- 情绪线索根据用户自己选择的标签做简单汇总；自评与“AI 回顾”均为前端本地演示逻辑，不调用真实模型 API。
- 自评不计算心理健康等级，也不构成医学量表或诊断。
- AI 回顾示例使用虚构内容；用户记录的回顾只读取本地日记，不会上传。
- 清除浏览器数据或更换设备后，记录不会自动迁移。
- 自我关怀内容不替代专业支持。

## 更新与发布

此仓库通过 GitHub Pages Actions 发布。更新页面文件并推送到 `main` 后，线上页面会自动更新，项目站点 URL 保持不变。
